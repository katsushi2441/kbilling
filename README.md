# kbilling — 請求書を発行して、そのまま支払ってもらう

**請求書をPDFで発行し、お客様専用のURLをメールで送る**システムです。
お客様はそのページから請求書をダウンロードし、**銀行振込またはPayPal**でお支払いいただけます。

- **データベース不要**（JSONファイルに `flock` で書きます）
- **外部ライブラリ不要**（PDFも自前で生成します。Composer も npm も使いません）
- **PHPが動く共有レンタルサーバーで動きます**（FTPで上げるだけ）
- **MIT License** — 商用利用・改変・再配布・再販が自由です

デモ: <https://proto.exbridge.jp/kbilling/>（パスワード `demo2026`・メールは送信されません）

## できること

| | |
|---|---|
| 請求書の発行 | 明細を最大12行、消費税10%/8%/0%、値引き行も書けます |
| 請求書PDF | 適格請求書（インボイス）の記載事項に対応。登録番号は設定したときだけ印字します |
| お客様への案内 | 推測困難なURL（32桁）をメールで送ります。お客様のログインは不要です |
| 支払い | 銀行振込（振込先を表示）／PayPal（クレジットカード可） |
| 入金の管理 | PayPalは自動、振込は管理画面から確認。期限超過が一覧で分かります |

## 設計上、譲っていないこと

**PayPalの入金は、必ずサーバー側で確かめてから記録します。**

PayPalボタンはブラウザの中で動くので、決済が終わると JavaScript が「終わりました」と
サーバーへ知らせにきます。**この知らせを信じてはいけません。**開発者ツールから同じ
リクエストを送るだけで、1円も払わずに入金済みにできるためです。

このシステムは PayPal の Orders API v2 に問い合わせ、次のすべてが合ったときだけ
入金として記録します（[kbilling_paypal.php](public/kbilling_paypal.php)）。

- 注文の状態が `COMPLETED`
- 通貨が `JPY`
- 金額が請求書の税込合計と一致する
- `custom_id` がその請求書のIDと一致する（他の決済の使い回しを防ぐ）

そのため、**`KBIL_PAYPAL_SECRET` を設定しないと決済ボタンを表示しません。**
確認できない決済は受け付けない、という方針です。

**振込先をコードに書いていません。**
発行元・住所・登録番号・振込先はすべて設定ファイルから読みます。設定するまで
請求書にも支払いページにも何も出ません。これは、買った人の請求書に別人の口座が
載る事故を構造的に防ぐためです。

## 動作要件

- **PHP 7.4 以上**（8.x で動作確認済み。PHP 5.x でも動く構文で書いています）
- `mail()` が使えること（使えなくても、支払いページのURLを手で伝えれば運用できます）
- **データベースは不要**
- 常駐プロセス・cron・Composer・npm はすべて不要
- PayPalを使う場合のみ、外部へのHTTPS通信（`curl` か `allow_url_fopen`）

## 設置

1. `public/` の中身をサーバーへ置く
2. `public/kbilling_config.php.example` をコピーして `kbilling_config.php` を作る
3. 管理パスワードのハッシュを作って貼る

   ```
   php scripts/make_password_hash.php 'あなたのパスワード'
   ```

4. 発行元と振込先を設定する（`KBIL_NAME` / `KBIL_MAIL_FROM` / `KBIL_BANK` …）
5. `kbilling.php` を開いてログイン

`kbilling_data/` は自動で作られます（書き込み権限が必要）。
設定を置くまで誰もログインできません。

### 共有サーバーでPHPのバージョンを選ぶ場合

heteml などでは `.htaccess` で指定します。置かないと古いPHPで動くことがあります。

```apache
AddHandler php8.3-script .php
```

## 確認

```
php scripts/check_kbilling.php
```

台帳・明細・税計算・入金記録・PayPalの照合・請求書PDFを確認します。
PayPalのAPIは呼ばないので、ネットワークが無くても実行できます。

## 消費税の端数について

小計をまとめてから課税し、端数は切り捨てます。**行ごとに税を計算して足しません。**

```
999円 + 999円 → 小計1,998円 → 消費税199円（切り捨て）
                行ごとだと 99 + 99 = 198円 になり、1円ずれます
```
